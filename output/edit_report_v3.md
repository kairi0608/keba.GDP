## 1. 結論

- **A/B の実写をレース本編（4.0〜33.5秒）に使った 60 秒のラフが完成**しました。B（一直線）でスタート → 逆光の振り返りで RUSH の前兆 → RUSH（17〜20秒）→ 20.0 秒の衝撃音で A の直線 → A のカーブ → オイルショック、の順です。

- 33.5 秒オイルショック → 36 秒政策カード → 39.9 秒 GDP 年表 → 44 秒で問いへ、の節目は指示どおりです。

## 5. 台本から変えたところ（理由つき）

| 元の台本 | v3 | 理由 |
|---|---|---|
| 1960年「高度経済成長期に突入！」 | 「高度経済成長、**さらに加速！**」 | 高度経済成長は 1950 年代半ばに始まっている。1960 年に始まったと言わないため（1955 のテロップで「始まる」と表示） |
| 「政策が変わった！順位も変わった！」 | 「政策が変わ**る**！順位も変わ**る**！」 | データ上、石油危機の直後に日本の順位は変わっていない（1972〜2009年は2位）。一般論の言い方にした |
| 1956年「景気拡大！日本、加速！」 | そのまま（10.4秒〜） | v2 で足していた「おっと、日本がここで加速！」は、B では日本が後方のため外した |
| 35〜50秒に大学の授業風景 | 50〜56.75秒（プレースホルダー） | v2 指示書の時間配分（44 秒で問い、50〜60 秒に授業と学生）を優先 |
| 「ゴール直前で動画一時停止」 | GDP 年表の「未来」ゾーンで、ゴール手前で一時停止 | ゴールに向かう実写がないため。実データ（2023年まで）の先は点線と「?」で、値は描いていない |
| 追加の実況 | 「おっと、ペースが上がってきた！」（RUSH 前兆）「所得倍増へ、ぐんぐん伸びる！」「さあカーブ！このまま行けるか、日本！」（カーブに入る瞬間）「カーブを抜けた！その先には…！？」（オイルショック前）「日本、ゴールへダッシュ！」 | 実況の空白を埋めるため。不要なら `timeline.json` から消すだけ |
| フランスは抜いてもいいかも | **残した**（5か国） | フランスのゼッケンの走者が実写に映っているため。抜くなら盤面・年表・ゲートの `COUNTRIES` から外す |

## 6. 自動テスト（`python scripts/test_output.py`、36/36 合格）

- 元素材が無改変（SHA-256 一致）×2
- タイムラインが 0〜60 秒で隙間・重なりなし／素材時計が素材の尺内
- A/B が 4〜33.5 秒のレース本編を占める／RUSH は 17 秒開始でカーブ直後／B は 20 秒で素材 0.0 秒から再開
- 節目 33.5／36／39台／44 秒／終盤 44〜60 秒で A/B 不使用
- 字幕どうしが重ならない／仮音声が次の台詞に食い込まない
- 字幕・テロップがセーフエリア内で重ならない（初回は 41〜44 秒の字幕が画面幅を超えて **不合格 → 改行を入れて修正**）／字幕の可読サイズ
- 本編・プレビューそれぞれ：尺（60.000s／34.000s）、1080x1920、30fps、H.264 yuv420p、フレーム数（1800／1020）、AAC、デコードエラーなし、黒コマなし、レース本編に静止なし、意図しない静止なし
- 音声：-15.0 LUFS、トゥルーピーク -1.4 dBTP、1.5 秒以上の無音なし

目視確認：主要 25 時点の静止画とコマ一覧で、タグが日本の走者を指すこと、テロップと字幕の重なり、年表の数値・順位を確認しました。

## 8. 応募規定と AI 利用について（重要）

募集要項は生成AI作品を禁止しています。このラフでは次の部分を AI（Claude Code）が作りました。

- 編集（カット割り・速度変化・色）、ゲート・RUSH・オイルショック・政策カード・GDP年表・問い・プレースホルダーのグラフィック（AI が書いたコードで描画）
- BGM・効果音（AI が書いたコードで合成）
- 仮の実況・ナレーション（Open JTalk による音声合成）

この作品が応募規定に適合するとは主張しません。最終版の作り方（人が編集し直す、人の声で録る、何をどこまで AI に頼ってよいか）は主催者に確認してください。画面右上の「ROUGH v2｜仮音声・仮グラフィック」表示はこのラフ用で、最終版では `render.py` の `badge()` の貼り付け 1 行を消すと外れます。
